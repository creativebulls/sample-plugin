# Draft a status update

Turn the user's notes into a short status update they can paste into chat, email, or a ticket.

## Gather

Use only details the user supplied. If a section has no information, write "None noted" instead of inventing work, dates, owners, or metrics.

Look for:

- What moved forward
- What is blocked, and who owns the unblock if the user named them
- What is next

## Write

Use this structure:

**Done**
- One bullet per completed item

**In progress**
- One bullet per active item, with the current state

**Blocked**
- One bullet per blocker, including the ask if the user stated one

**Next**
- One to three bullets for the immediate next steps

Keep the whole update under 150 words. Use the user's product names and dates exactly as given. Do not add a greeting or sign-off unless the user asks for one.
